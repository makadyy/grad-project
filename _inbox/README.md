# _inbox — drop zone

Drop raw source material here and I'll process it into the repo.

## Right now: WhatsApp team chat export

From WhatsApp: open the grad project group → **⋮ → More → Export chat → Attach media** →
save the `.zip` into this folder.

**Attach media** matters — it pulls in voice notes, images, and any files (slides,
notebooks, PDFs) the team shared. Without it you only get text and every attachment
becomes a `<Media omitted>` placeholder.

Once the `.zip` is here, tell me and I'll:

1. Extract it
2. Transcribe Arabic voice notes with Whisper
3. Strip WhatsApp system noise
4. Inline transcriptions into a clean `chat-log.txt`
5. Sort attachments into `images/`, `slides/`, `project/`
6. Read it all and pull out the actual deliverable list, owners, and deadlines

Re-exports are fine later — processing is incremental, so nothing gets duplicated.
